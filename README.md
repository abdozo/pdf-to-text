# ورّاق

تطبيق سطح مكتب عربي لتحويل كتب PDF المصوّرة إلى نص قابل للمراجعة والتصدير إلى Word وMarkdown وHTML تفاعلي. يعمل محليًا بواجهة PySide6 وQt Quick، ولا يشغّل خادم ويب أو يفتح واجهة في المتصفح.

## التشغيل على macOS

افتح مجلد `Mac Commands` وانقر مرتين على `Start-Warraq.command`. ينشئ المشغّل بيئة `.venv-desktop` عند الحاجة، ثم يفتح تطبيق ورّاق. استخدم `Stop-Warraq.command` لإغلاقه أو `Restart-Warraq.command` لإعادة تشغيله. يسجل المشغّل أخطاء التشغيل في `.waraq-runtime/waraq.log`، ولا يعيد تثبيت الاعتماديات إلا عند تغير `requirements-desktop.txt`.

للتشغيل من الطرفية:

```sh
python3 -m venv .venv-desktop
.venv-desktop/bin/python -m pip install -r requirements-desktop.txt
.venv-desktop/bin/python run_desktop.py
```

## المراجعة والتحرير

شاشة المراجعة لها وضع واحد: صورة الصفحة الأصلية والنص جنبًا إلى جنب. يظهر النص كله في محرر WYSIWYG واحد لكل صفحة، مبني على Tiptap ومضمّن محليًا داخل نافذة التطبيق. يعيد نموذج التحويل JSON هجينًا وخفيفًا: نوع السطر (`p` أو `h2`–`h6` أو `note` أو `hr`) مع نص Markdown داخلي، ثم يولّد التطبيق علامات Markdown البنائية ويحفظها. يبقى كل سطر مصدري كتلة مستقلة، مع التفاف طبيعي عند تضييق النافذة من دون دمجه بالسطر التالي. يوسّط التطبيق العناوين ويصغّر الحواشي تلقائيًا، ويتيح زر `MD` نسخ المصدر للتجربة في قارئ آخر. تبقى الصفحات القديمة المحفوظة كـHTML قابلة للتحرير بأدوات التنسيق السابقة.

لا توجد أدوات مطابقة فوق الأصل ولا إعدادات لبنية الصفحة. يعرض زر الصفحة «تحويل الصفحة» قبل نجاح أول تحويل، ثم «إعادة تحويل الصفحة» بعده. تُحفظ تغييرات المحرر تلقائيًا في قاعدة SQLite، ويمكن أيضًا الضغط على «حفظ» أو «اعتماد الصفحة». يعيد زر «إعادة النص الأصلي» الصفحة المفتوحة وحدها إلى آخر نص وصل من الذكاء الاصطناعي.

## عمليات التحويل

من شاشة «تحويل صفحات» يمكن اختيار نسخ النص أو ترجمته أو تلخيصه. في النسخ والترجمة تبقى كل صفحة PDF مرتبطة بصفحة ناتج واحدة، مع العناوين والحواشي والهوامش. للترجمة لغة واتجاه كتابة محددان، ولا تُفرض مقابلة سطر بسطر. لتغيير ناتج نسخة أو ترجمة مكتملة، فعّل «إعادة تحويل الصفحات المكتملة».

في التلخيص تُعالج صفحات كل دفعة كوحدة واحدة، ويُنتج النموذج ورقة أو أكثر بأربعة أرباع: التلخيص الاستيعابي، والفلسفة والفوائد، والنقد والاستشكالات، والتطبيقات والتوصيات. البرومبت مبني على منهج المستخدم الأصلي مع استقلال كل ربع، وحذف المقارنة المعرفية والوسوم. كل فكرة تحمل إحالة إلى رقم صفحة PDF ابتداءً من 1، وليس الرقم المطبوع. ترفض الاستجابة إذا غاب ربع أو حملت إحالة خارج صفحات المصدر. تُحفظ الملخصات منفصلة عن النصوص المنسوخة والمترجمة؛ لذلك لا يلزم تفعيل إعادة التحويل لتلخيص صفحات سبق نسخها. لا يُرسل ملخص الدفعات السابقة مع الدفعة الجديدة.

من شاشة «الملخصات» اختر الكتاب وسلسلة النتائج: الملخصات الأصلية أو نتائج إحدى المراجعات. حدد ما تريد مراجعته واضغط «مراجعة الملخصات المحددة». تُقسّم المجموعة تلقائيًا إلى دفعات صغيرة، مع تقسيم الملخص الطويل نفسه عند الحاجة دون إسقاط نصه. اختر عدد الملخصات في الاستعلام (الافتراضي 3). يراجع الاستعلام المجموعة معًا ويقرأ قدرًا محدودًا من السابق المراجع والتالي لفهم التتمة وحذف التكرار. يمكن أن ينتج عدد أوراق أقل أو أكثر بحسب المادة، مع الحفاظ على ترتيب صفحات المصدر. تحفظ النتائج كوحدات مستقلة في سلسلة جديدة؛ لا يُطلب ملخص واحد للمجموعة كلها. يبقى حد 120,000 بايت لكل طلب، ولا يُطبّق على مجموع المختارات. تحفظ خطة الدفعات وتقدمها ونتائجها للاستئناف، وتتوقف السلسلة عند فشل دفعة إلى أن تعاد محاولتها، حتى لا يُبنى الترابط على نتيجة مفقودة.

تعرض الشاشة عداد دفعات المراجعة، وتبقى الأصول والنسخ السابقة محفوظة. لا تُحدد نسخة مراجعة مع أصلها في العملية نفسها، لكن يمكن مراجعة سلسلة النتائج الجديدة كاملة. يكتب التلخيص والمراجعة الأفكار والاقتباسات مباشرة دون مقدمات متكررة مثل «قال المؤلف»، مع حفظ نص الاقتباس الحرفي. الضغط على إحالة PDF يفتح الأصل.

عند تحديد عدة ملخصات يعرض الزر «تصدير المحدد» ويصدّر جميع أوراقها بترتيب المصدر، دون دمجها بالذكاء الاصطناعي. عند غياب التحديد يصدّر المعروض فقط. الصيغ هي HTML وWord بتخطيط الأرباع، وMarkdown بأقسام متتابعة. تمتد المادة حسب حجمها دون قصها لتناسب صفحة ثابتة؛ وقد تمتد الورقة المنطقية إلى عدة صفحات مطبوعة. شاشة الأرباع للعرض والتتبع، وتبقى أدوات تحرير النسخ والترجمة في شاشة المراجعة. تواصل مهام التلخيص القديمة المحفوظة قبل هذا التحديث العمل بعقد الصفحات القديم؛ تطبق المهام الجديدة عقد الأرباع.

تتيح «الإعدادات المتقدمة» كتابة تعليمات إضافية خاصة بالمهمة. يضيفها ورّاق إلى البرومبت قبل إرسال الصفحات إلى Gemini، ويحفظها مع المهمة لاستعادتها عند تعديل إعداداتها.

تستمر مهمة التحويل عند التنقل بين صفحات التطبيق. يمكن فتح «عمليات التحويل» من القائمة الجانبية لمتابعة الدفعة الجارية والصفحات المحفوظة والمتبقية والفاشلة، أو للرجوع إلى مهمة سابقة.

يختار المستخدم عدد الصفحات في الاستعلام الواحد. يرسل ورّاق كل صفحة كصورة مستقلة داخل الطلب، ويتحقق من رقمها قبل حفظ النتيجة. يحسب سجل الاستهلاك الدفعة كلها كاستعلام واحد ويعرض أرقام الصفحات التي شملها.

يمكن تعليق المهمة بعد الدفعة الجارية واستئنافها لاحقًا من الموضع نفسه. لا يعيد الاستئناف الصفحات التي حفظتها المهمة. يلغي زر الإلغاء المهمة فورًا ويتيح بدء مهمة جديدة، ويتجاهل أي رد متأخر من طلب الشبكة الملغى، بينما تبقى كل صفحة اكتمل تحويلها محفوظة وقابلة للمراجعة. ويمكن تشغيل صوت نظام عند اكتمال المهمة أو فشلها أو إلغائها. إذا أُغلق التطبيق أثناء التحويل، تظهر المهمة كمتوقفة عند تشغيله من جديد ويمكن استئنافها.

## البيانات والخصوصية

- يحفظ التطبيق مكتبته في `~/Library/Application Support/Warraq` على macOS و`%LOCALAPPDATA%\Warraq` على Windows.
- لا ينسخ التطبيق ملفات PDF عند إضافتها. تحفظ قاعدة البيانات مسار الملف الأصلي. إذا نُقل الملف، افتح الكتاب واختر «تغيير ملف PDF» لإعادة ربطه مع بقاء التحويلات والمراجعات المحفوظة.
- يمكن تعديل اسم الكتاب أو حذفه من شاشة الكتاب. لا يحذف ورّاق ملف PDF نفسه من الجهاز.
- تبقى قاعدة البيانات وملفات PDF والنسخ الناتجة محلية.
- تُرسل فقط صفحات التحويل التي يختارها المستخدم إلى Gemini.
- يضيف المستخدم مفاتيح Gemini بأسماء يختارها، من دون إنشاء سجلات لمشروعات Google.
- تُحفظ أسرار مفاتيح Gemini في Keychain، ولا تدخل قاعدة البيانات أو سجل الطلبات. ويمكن حذف المفتاح من التطبيق ومن Keychain معًا. لا يلغي الحذف المحلي المفتاح من Google AI Studio.
- حزمة Tiptap مضمنة داخل التطبيق؛ لا يعتمد المحرر على CDN أو اتصال بالإنترنت.
- تحفظ النسخة الاحتياطية قاعدة البيانات والنصوص والإعدادات فقط، ولا تضم ملفات PDF أو مفاتيح Gemini.

## الاختبارات

```sh
.venv-desktop/bin/python -m pytest -q tests_desktop
```

عند تعديل `waraq/editor/editor.js`، أعد بناء الحزمة المحلية قبل تشغيل الاختبارات أو إنشاء التطبيق:

```sh
npm ci
npm run build:editor
```

## بناء حزمة macOS

```sh
./scripts/build_macos.sh
```

تفاصيل البناء والبيانات في [docs/desktop-macos.md](docs/desktop-macos.md).

## بناء مثبت Windows

على جهاز Windows x64 يشمل Python 3.12 وأدوات MSVC وInno Setup:

```powershell
.\scripts\build_windows.ps1
```

ينتج السكربت تطبيقًا مستقلًا ثم `Warraq-Setup-<version>.exe`. التفاصيل في [docs/desktop-windows.md](docs/desktop-windows.md).

## التشغيل من المصدر على Windows

افتح مجلد `Windows Commands` وانقر مرتين على `Start-Warraq.cmd` للتشغيل، أو `Stop-Warraq.cmd` للإيقاف، أو `Restart-Warraq.cmd` لإعادة التشغيل. يتطلب التشغيل من المصدر Python 3.11 أو أحدث.

يوقف `Update-Warraq.cmd` التطبيق، وينتقل إلى فرع `main`، ويسحب آخر التغييرات باستخدام Git، ثم يشغّل التطبيق من جديد. إذا فشل أمر Git، يبقى التطبيق متوقفًا وتظهر رسالة الخطأ بدل تشغيل نسخة ناقصة التحديث.

التلخيص الأولي والمراجعة يكتبان الأفكار مباشرة دون سرد أفعال المؤلف. يفحص التطبيق بقاء عبارتي المؤلف والمصنف خارج الاقتباسات؛ وعند وجودهما يطلب تصحيحًا لغويًا محدودًا (محاولتان كحد أقصى) قبل الحفظ. كل طلب تصحيح مسجل في الاستهلاك. الإحالات وبنية الأقسام ثابتة أثناء التصحيح، وتُرفض التغييرات في الاقتباسات المعلّمة والأرقام. تحظر التعليمات تغيير المعنى والقيود والأسماء ودرجة الجزم؛ وتبقى مراجعة المعنى بشريًا ضرورية عند التدقيق العلمي. النتائج القديمة لا تتغير تلقائيًا.

بقاء عبارة عن المؤلف بعد محاولتي التصحيح لا يوقف المعالجة؛ تُحفظ النتيجة مع ملاحظة صياغية وتستمر الدفعات التالية. من شاشة الملخصات يمكن حذف سلسلة مراجعة سابقة بعد تأكيد الحذف، مع حفظ الأصول والمراجعات الأخرى وسجل الاستهلاك. لا يمكن حذف مراجعة تعمل أو نتائج تعتمد عليها مراجعة غير مكتملة.

تتيح شاشة الملخصات حذف المحدد أو حذف القائمة المعروضة كاملة، للملخصات الأصلية ونتائج المراجعات. يعرض التأكيد عدد العناصر. تبقى العناصر غير المحددة وملفات PDF وسجلات الاستهلاك، ويُمنع الحذف أثناء إنتاج النتائج أو عند اعتماد مراجعة غير مكتملة عليها. حذف نتائج مهمة معلقة يلغي استئناف تلك المهمة حتى لا يعود عبر نتيجة محذوفة.
